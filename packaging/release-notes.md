Windows 10 / 11（64 位）免安装版，下载 AIUsage.exe 双击即可使用。

- 主界面新增“检查更新”，可自行选择是否升级。
- 有新版本时，机器人脚下显示红色 New 按钮。
- 点击 New，在屏幕中央查看版本与更新说明，确认后才下载。
- 下载可取消；完成校验后自动替换并重新打开，保留账号配置和用量记录。
- 保留上一版程序，替换或启动失败时尝试恢复。

v0.4.1 及更早版本首次升级：退出挂件，用新版 EXE 替换旧版，保留 settings.json 和 snapshot.json；之后可在程序内更新。

无需 Python、无需解压、无需管理员权限。Codex 沿用本机登录，其他平台在“连接设置”填写 API 密钥。
